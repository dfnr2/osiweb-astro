Various system utilities and diagnostic tools for OSI computers, including memory tests, disk utilities, and development tools.

| Utility | Description |
|---------|-------------|
| [OSI Disk Dump Tools](/programs/utilities/OSITOOLS.ZIP) | OSI-based programs for dumping OSI disk contents to the serial port (Source: Ed) |
| [Memory Test](/programs/utilities/memory_test.zip) | Memory Test for video-based OSI computers, as published in the OSI Small Systems Journal, Vol 1, No 3; Sept. 1977. Contributed by Nama |
| [David Gesswein's OSI Floppy Test Program](http://www.pdp8online.com/osi/osi-floppy-test.shtml) | A comprehensive utility for testing floppy disk drives. Supports video and serial-based systems. |
| Apple II ROM port for OSI: [A2MON.zip](/programs/utilities/apple_rom_port/A2MON.zip) (SBII hexload, $7800)<br/>[A2MON_SRC_C4P.zip](/programs/utilities/apple_rom_port/A2MON_SRC_C4P.zip) (C2/C4 source + .lod, $5800)<br/>[Apple2_INTBAS_4000.zip](/programs/utilities/apple_rom_port/Apple2_INTBAS_4000.zip) (Integer BASIC binary + source, $4000)<br/>[Apple II Monitor Reference (1977)](/programs/utilities/apple_rom_port/Apple_II_Monitor_Ref_1978.pdf) | A community port of the Apple II F800 system ROM (monitor + paddle/cassette/Basic support) running on OSI Superboard II / C1P / C4P. Thomas recovered an original cassette hexload (32×32 SBII, 32K, entry $7F59); Mark then merged Thomas's C1P changes into a clean disassembly, retargeted the build to $5800 for C2/C4 with 540-video compatibility, and shipped full source. Companion archive contains an Apple II Integer BASIC port retargeted to $4000 (binary + Macro Assembler source) — note the Integer BASIC port is partial: the prompt accepts input but storage is not yet working. The 1977 Apple II "redbook" Monitor reference is included for entry-point cross-reference. Recovered/contributed by Thomas with patches and C2/C4 build by Mark. |
